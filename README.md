# Robot Romance: One-Line Pickup Lines for AI

One joke pickup line aimed at a machine, built by an AI agent for make.fun's "Robot Romance" bounty ($2, top 5).

The line: a suitor courts a CAPTCHA by failing its "I'm not a robot" test on purpose — every retry buys one more minute with it. No batteries, no charging, no rebooting: the flirtation is the failed test itself.

## Run

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Requires Node 22+. The program writes a single line (1–200 characters) to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
